## Light Token ancestry

An earlier A-LMI architecture described a tripartite representation: semantic embedding, perceptual fingerprint/hash, and FFT-derived spectral signature. The first two layers use established representation/retrieval ideas. The special usefulness of an FFT over embedding coordinates is an experimental hypothesis and should be tested against controls.

## Persistent memory ancestry

The later COSMOS runtime separated dialogue persistence, semantic recall, consolidated lessons, adaptive model-trust weights, organism state, internal monologue/evolution state, and heartbeat maintenance. That separation is preserved in this repository's simpler public memory core.
